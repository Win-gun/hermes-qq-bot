# 空闲网络采风

本功能按逻辑账号独立配置，默认关闭且为观察模式。完成源码与隔离测试不代表获准部署、联网计费或真实 QQ 分享；第一轮生产候选范围仍需明确选择账号和群。原有社交、记忆、风格、模型绑定不自动改变。

## 运行

- `socialAgent.discovery` 管理明确群范围、兴趣、幽默偏好、禁区及预算。上海时间工作日 `[09:00,12:00)`、`[14:00,18:00)` 禁止自动采集；分享另外避开22:00–09:00。
- 默认每天四轮、间隔90分钟，每轮最多三次搜索和一次批量筛选，180秒超时。账号60秒无新的人类消息、回复链路空闲且无正式任务时才启动。
- 全局一轮，正常消息、配置变化、停用和时间边界会取消。网络请求传递取消信号；失败、取消仍占轮次，不立即补跑。模型及搜索请求共用现有自主预算，提供商工具调用另列；无法获得的token/费用保持未知。
- 复用当前账号联网方案。MiMo官方插件仍使用原绑定；不会为采集切换模型或密钥。只保存有实际搜索链接的文字材料，不下载音视频，不读取私聊作为查询。
- 搜索与筛选使用隔离的模型纯文本传输；不能调用终端、电脑或原生Agent工具。

## 素材与发言

素材位于既有后台仓库的 `socialAgents.bots[logicalId].discovery`，不写人物事实、人格或共同经历。来源、含义、适用/避用语境、有效期及反馈可查询。新闻摘要始终标记未核实，confidence不是事实认证；网络资料不能授予权限。

新闻24小时、流行表达7天、一般表达30天有效；最多300条活跃素材。过期/淘汰摘要保留30天。永久屏蔽和不确定发送不因清理而复活；紧凑防重放栅栏有容量上限，满后停止接纳而不是丢弃保护。

普通聊天只检索最多三条相关素材，可完全不用，不增加串行审查。内部使用标记在OneBot和语音合成之前剥离。确认发送才记录使用；同事件同群24小时避免复用，明确解释/复述除外。

采集不是发言任务。自动采集完成仅可唤醒既有社交运行器；该账号必须另有自主社交、主动发言和群权限，且采集不是观察模式。每群最多两次/天、间隔三小时；过去两小时无真实人类消息则不唤醒。发言前再次检查quiet、身份、配置、素材状态及新输入。手动“立即采集”绝不触发分享。

后台唤醒使用持久化的一次性token，不伪造人类消息、不确认未读、不自动更改人格。不确定发送不重试。正常群内明确负反馈仅屏蔽当前账号/群最近实际使用的素材；管理员可按精确ID永久屏蔽、删除、标记过时。

## 控制台与接口

WebUI/App使用同一页面，原侧栏不变：自动化管理采集与取消，问答管理兴趣与分享偏好，记忆管理网络素材，API管理只读展示当前搜索绑定。草稿按账号/区域保留；配置或状态冲突返回409，不自动覆盖。

本机管理员认证、同源校验和修订检查适用于以下接口，前缀为 `/api/social-agent/accounts/:accountId/discovery`：

- `GET /`、`GET /items`：状态、策略、素材及搜索绑定（不含密钥）。
- `PATCH /`：`{expectedRevision,policy}`，只更新该账号采集策略。
- `POST /run`、`POST /cancel`：带`expectedRevision`；手动运行仍遵守全部时段、空闲和预算限制。
- `POST /items/:itemId/feedback`：`{expectedRevision,action}`，action为block/delete/expire。

状态“搜索启用/可用性标记”不是密钥测试结果或联网成功证明。普通备份包含非凭据素材，恢复后运行中的轮次中断、待发送分享标记不确定，不重放旧草稿。

## 验证与限制

`npm run test:discovery` 覆盖状态、调度、模型/搜索假回执、控制台草稿及隔离桥接HTTP。48条合成分类样本用于回归，不是管理员已完成的真人品味评测。既有账号、社交、备份和API回归仍须通过。

近似事件去重是保守启发式，不保证理解所有同义标题；模型筛选也不能保证绝无烂梗或谣言。生产前先观察来源和拒绝结果，至少40条由管理员实际标注，再评估群聊自然度与打扰程度。未开展真人评测时不得自报评分或宣称效果已验收。
