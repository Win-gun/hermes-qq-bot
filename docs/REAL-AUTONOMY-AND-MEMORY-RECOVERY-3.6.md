拍一拍、原生回应和提及，各自只有既有的一处自主会话范围。主账号 Discovery 开启，

工具表提供空间读取。两账号空间读／发表／赞／评论的协议证明均为 unknown，未试写。
已有管理 API 显示这些运行时能力；没有用“已注册”或“在线”代替“真实执行通过”。

解除预算。参考 [qq-chat-v2](https://github.com/Derpyu520/qq-bridge/blob/main/dsh/agent-presets/qq-chat-v2/agent.cordis.yml)
