# 开源发布前清单

当前状态：`1.0.0-beta.4` 已在隔离目录完成本机验收；此清单区分已验证项目与仍需跨设备验证的项目。执行时只记录扫描结论和必要的文件路径，不复制密钥、聊天内容或完整扫描命中行到报告。

`npm run source:preview` 可以生成不含旧 Git 历史的源码候选包；它不能替代专用秘密扫描、干净机器验收和所有者发布决定。WebUI 发行包用 `npm run web:release:package` 生成，App 用 `npm run app:make` 构建。
