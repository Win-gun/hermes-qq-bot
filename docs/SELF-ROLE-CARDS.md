# AI 自主互动与自写成长卡

每个逻辑 bot 独立决定是否回应、等待、潜水，以及在宿主提供的候选内使用文字、
语音、表情、消息回应、提及或拍一拍。已启用 Social Agent 的会话不再经过旧的
概率抽签主动回复；直接问题保留快速路径。能力不可用、缺少真实来源或会话未授权时，
不能仅因模型想用就调用。公开空间、跨会话私聊和声音克隆不因此获得新权限。

可以降低表情/回应等软冷却、选择“积极参与”表达预设，但 quiet、停止、真实 QQ
隔离、同意、协议能力证据、反循环、发送间隔和模型预算是执行边界，不是提示建议。
语音只在账号已允许 record、语音服务已启用、会话为 mixed 时提供给 AI。
关闭仍关闭；force 仍由原语音路径处理，不重复发送。语音没有 wire 尝试时才可降级文字；
超时和不确定回执绝不自动重发。AI 自选 TTS 计入同一逻辑账号自主调用预算。

## 角色卡分层

- 原始账号提示词和核心身份：逐字保留，复制新账号时仍是独立快照，不建立继承。
- 自写成长卡：只包含 `expression`、`interests`、`examples`，不是权限或人物事实。
  每次有独立修订、理由、来源引用和完整字段快照；不覆盖旧版本、不自动淘汰历史。
- 核心 identity/selfName/boundaries 提案继续走管理员审核；不让模型覆盖权限、工具、
  模型绑定、角色核心或其他账号的人设。

策略为账号 `socialAgent.roleCard`：

```json
{ "enabled": false, "autoGrow": false, "minUpdateIntervalMs": 86400000, "maxVersions": 32 }
```

默认关闭，不增加既有账号主动范围。开启后，管理员可以在问答页面确认“生成并采用”，
或者在对应账号使用 `/bot rolecard write [发展方向]`。多 bot 群继续使用 `/bot a`、
`/bot b` 路由；`/bot rolecard status` 查看本 bot 当前成长卡。先简短应答，再生成。
显式生成复用当前绑定的文字模型，只传原人设、当前成长卡和指定主题，不提供群聊、
私聊、联系人、文件、浏览器或原生工具；计入同一自主预算，不额外开隐藏模型。

`autoGrow` 开启后，后台连续性模型可以基于自己真实读过的、同一发送者的群互动，
提出表达、兴趣与示例的成长。程序再校验来源、时间、修订和字段；默认一天至多一次。
私聊或跨会话联系中的信息不得自动写入可在群中投影的成长卡；仍可作为待管理员核对的
原有提案。核心变更仍须审核。后台成长不增加普通首答串行调用，不发送成长通知。

到达版本容量时停止写入并显示背压，不删除早期人格；管理员可备份后调整容量
（最多 64），而不是用 FIFO 覆盖历史。普通备份保存非凭据成长卡及版本，恢复后不重放生成。

## 接口与验收

均需现有本机管理会话；修改校验 Origin、配置修订和成长卡修订。

- `GET /api/social-agent/accounts/:id/role-card`：本地只读，不调用模型、不发 QQ。
- `POST .../role-card/generate`：`{expectedRevision,cardRevision,topic}`，一次显式生成并采用。
  `expectedRevision` 是此 GET 的配置修订，不是社交连续性状态哈希。
- 候选无效、超时、撤销或持久化不确定时不自动重试；用户刷新核对实际版本。

运行 `npm run test:self-role-card`、`npm run test:social-agent`、账号隔离、语音、
备份与控制台回归；另做共享页面真实交互、App 打包一致性及生产范围核对。
合成音频回转不能替代真人 ASR、客户端播放与人格自然度评测。
