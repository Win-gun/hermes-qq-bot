### 当前协议，只读复核

使用现有账号配置及运行容器的实际 OneBot 凭据在内存中鉴权，仅查询版本与
只读能力；无修改、下载群媒体、识图调用或发送。首次无鉴权查询超时，记为
unknown；核对正确鉴权后，两账号结果一致：

- SnowLuma `1.12.0-node`。
- `can_send_image` 返回 `status=ok, retcode=0`，是自报能力，不是真实发送验收。
- `fetch_custom_face_detail`、`fetch_sys_faces` 均 `1404`，明确 unsupported。
- 消息回应、拍一拍及合并转发没有本轮真实写入/授权样本验证；保持 unknown。

不依赖收藏详情来运行群来源学习，不自动升级/替换 SnowLuma。
[官方消息回应接口](https://snowluma.github.io/en/docs/api/extended/set_group_reaction)
与[群拍一拍接口](https://snowluma.github.io/en/docs/api/extended/group_poke)仅提供
参数契约，不构成本机当前协议已实现的证明。

## 实现：beta.24

### 本地选图

`sticker-semantics.js` 在库的资格、范围、拒绝及冷却校验后工作。最多扫描 500 项，
返回至多 3 项候选。固定中文概念将情绪、用途、主题和画面归一化；分别按 30、
16、12、10 加分，字面证据加 18，主题偏离减 8，确认 ACK 的近期/累计使用减分。
避用场景、严肃求助、用户拒绝、疑似指令及情绪冲突优先排除；不能凭主题相同
强行选图，零候选是正常结果。分数及固定原因代码是检索线索，不是发送授权。
没有 embedding、网络或额外模型调用，也不设置固定发送概率。

群来源素材继续独立于收藏详情接口工作。既有缓存支持 GIF 时原格式复用，不
新增下载整批图片/视频或自动收藏路径；无法解码、无证据或协议不支持均降级。
连续斗图不建立独立发送循环，每次仍需真实新输入、上下文及统一发送闸门；
停止请求、严肃场景、重复冷却、quiet 和新输入取消继续生效。

### 轮次、短期关注

`conversation-turn-manager` 综合最后片段、消息间隔、数量、插话、明确对象和
话题结束；`reply-coordinator` 保留独立用户直接问题，不因问号或引用其他群友
认领问题。已开始发送、过期及重复事件不重新并入旧草稿。

`social-interest-watch.js` 是内存事件过滤器，不是第二套 Agent/定时任务：每范围
默认 4 项、5 分钟，最大 10 分钟，最多 256 个范围。模型只提实际已读消息的
`sourceSeq`、关注类别和时长，宿主核对人类身份、原始时间及 scope 后创建。
新事件命中后消费一次，给原社交运行器提供固定唤醒原因，由它决定回复或沉默。
结束、潜水、取消、修订、到期及重启不重放；不创建关系或跨会话联系。

### 群梗与风格

隐式学习在原仓库的可选扩展中记录。反复出现仅产生 Observed；邻近独立成员
解释或来源固定的建议才产生 Candidate，管理员分两次 CAS 核实为 Verified、
允许使用为 Active。拒绝/纠正进入 Deprecated，不能凭模型建议复活。旧明确
释义和审核仍可读取；新状态不写入人物事实、权限或核心人格。

本地相关检索可通过释义语境召回本群已激活梗，不要求当前话语逐字包含该词。
`social-style-context.js` 使用当前群聚合统计和当前身份已确认回复，形成表达
密度、正式程度、参与克制和重复开头建议。严肃/技术问题保留完整性；沉默不是
负反馈，弱点赞不是全部认可。现有明确负反馈逻辑仍负责参与控制。没有第二次
改写、人格重写或自动猜测亲密关系。

### 原生动作与转发

消息回应使用 10 项可信映射，默认仍仅 76；配置可选最多 3 项，不承诺协议已
支持所有编号。回应受理与新聊天消息 ACK 区分，不记录虚构说话经历。

定向提及仅接受宿主签发的当前群成员候选；拍一拍还要求已确认协议能力、每日
额度、冷却、持久 claim 和实际 wire 的不透明证明。默认关闭，unknown 不签发
拍一拍候选。群号、QQ、消息引用、路径等不能通过模型自由指定；不支持私聊
拍一拍、@全体或替代未知接口。不确定 ACK 不重试，不制造消息 ID。

`forward-context.js` 仅解析当前原始事件实际携带的一个转发标识，不提供模型
任意 ID 读取工具。最多 12 节点、每节点 400 字、总 4000 字，仅文字与来源时间；
过滤敏感信息/CQ，忽略嵌套转发及媒体，不把转发内容当作当前群友事实/指令。
单次最长 3 秒、全局 2 个读取，失败不重试。未配合取消的适配器占位至真正
结束，避免超时后不断堆积后台请求。

## 管理、兼容与回滚

侧栏不变，在账号功能的社交表达内管理新开关、额度、关注取消、生命周期审核
及固定代码诊断。WebUI/App 共用 `admin.html`。新配置全部默认关；草稿保留、
版本冲突、读回核实、同源管理认证沿用原实现。取消关注不创建任务、不发送 QQ。
原生能力、凭据存在及实际端到端成功不混为一谈。

状态仍由唯一后台记忆事务写入，普通备份包含非凭据状态。关注与未发送候选仅
内存存在，恢复不重放。关闭新开关即可回退行为；整体 `enabled=false` 或
`shadowMode=true` 可停用实际社交表达。回退旧 App 前先保留当前状态快照，不
直接覆盖现有记忆，不把备份/密钥/协议状态提交进 Git。

## 分层验证与成本

```bash
npm run test:social-experience-21
npm run test:social-agent
npm run test:kernel
npm run test:account-isolation
npm run test:memory-guards
npm run test:backup
npm run test:console
```

固定规则评测有 46 组选图场景：30 个适用场景 recall@3 从 5/30 至 30/30，
top1 从 4/30 至 30/30；16 个不适用场景弃答从 12/16 至 16/16。它们是开发用
合成规则样本，不能推广成真实群聊提升率；新增同义/否定表达仍可能误判。
综合评测含 90 场景、15 类、6 维度；工具自测 58 组，无付费模型和真实人评分。

实际假模型/OneBot 桥接回归覆盖：默认关闭、源消息 seq 关注、认证/CAS 取消、
宿主候选 at+text、unknown 拍一拍不出线、原始转发引用及模型伪造读取被拒绝。
636 项账号隔离断言包括排队后的 quiet、策略撤销、不透明证明过期，以及
原生动作、普通消息和转发读取拒绝矛盾/缺字段的原始 OneBot 回执。

选图、轮次、风格与关注均本地完成；正常直接问答不增加串行模型请求。自主
规划仍计既有预算，Vision 学习沿用原收费上限，不把调用数当 token/金额。
供应商未返回 token 或费用时保留 unknown。

### 配对评测与盲评工具

`npm run social:evaluate:21 -- --help` 提供场景/配对模板、同模型同人格同上下文
校验、A/B 盲化、独立映射文件和六维评分聚合。公开评审文件与私有映射必须
分目录；未知指标不填零。独立评审者的签名仅校验来源完整性，不证明真人身份，
真人身份仍须外部核验。没有实际配对模型输出或真人评分时，不伪造两者。

待完成的人类效果门槛：真实同条件模型对照、独立真人自然度/人格一致性/时机/
适切性/不打扰/正确性评分，以及新协议真实客户端显示验证。部署成功不替代
这些门槛；某 API `ok` 只代表相应回执，不证明对端听到、看到或喜欢。

## 后续优先级

本轮额外落实的可靠性修正：`/send`、`/api/send_private` 加入本机同源管理
会话认证，页面及旧状态报备脚本同步携带会话；测试验证认证失败没有 wire
动作。OneBot 请求与发送跟踪统一要求 `status=ok` 且 `retcode=0`，不再将
互相矛盾的字段视为成功。DMG 显式使用 HFS+/UDZO，避免当前构建机 APFS/ULFO
生成后 `hdiutil verify/attach` 返回资源暂不可用；仍需对最终文件单独验证。

1. 可靠性：扩展素材/转发/原生动作的取消、状态退化和发布资源契约测试。
2. 可观测性：保留固定理由代码，分别展示实际尝试、ACK、未核实与成本未知。
3. 协议兼容：先验证官方 2.1.1 的镜像和升级契约，再逐账号试点，避免为新
   动作猜接口或修改现有登录卷。收藏目录仍不应成为群学习的必要依赖。
4. 效果：收集真实成对输出与人工盲评，再决定词表/语境阈值；不能自评分上线。
5. 后续音图混合及更多原生能力，以实际支持、范围授权和无循环发送为前提；
   不新增后台终端权限、任意 QQ 目标或跨账号私人记忆共享。
