# 控制台视觉体系

WebUI 和桌面 App 使用同一份 `public/admin.html`、`public/console.css`、`public/console-theme.js`。导航名称、顺序与业务配置保持不变；模型、账号、记忆和发送规则不由视觉设置修改。

## 设计基线

[可编辑 Figma 设计稿](https://www.figma.com/design/pMBqg9qFmj2JLHGDB2Yze6) 使用虚构数据，包含深浅总览、账号功能、API 管理和窄屏布局。

- 中性石墨灰 / 柔和灰白，蓝紫强调色，无远程字体、CDN、渐变或发光背景。
- 页面标题 24px、区域标题 16px、正文 14px、辅助文字 12px。
- 4/8px 间距体系，36px 常规控件，12px 卡片圆角。
- 当前状态与常用操作优先；协议参数、诊断证据和高级设置按需展开。
- 原有分区域保存、草稿保留和版本冲突处理继续生效。

## 外观偏好

首次默认深色，可切换浅色或跟随系统。浏览器偏好保存在本机 localStorage；桌面偏好单独保存在应用状态目录的 `desktop-theme.json`，通过严格枚举 IPC 同步窗口背景，不写入机器人配置。存储不可用时界面仍可使用；系统主题变化即时更新。主题脚本在样式表之前加载。

## 响应式与可访问性

- ≥1100px：完整侧栏；768–1099px：紧凑侧栏。
- <768px：顶部主题选择与抽屉导航；支持 Escape、焦点约束和关闭后焦点恢复。
- 表单按宽度切换列数，长字段可换行；日志和产物有独立阅读空间。
- 统一可见键盘焦点、状态文字、禁用反馈和减少动态效果设置。

## 隔离验收

```bash
npm run test:console
npm run console:preview
```

预览仅监听 `127.0.0.1:6328`。只读取安全示例配置与页面资源，账号、任务、存档和备份全部为虚构数据；保存仅写内存，退出即丢弃。不会调用模型、Docker、Hermes、QQ 或现有用户数据。不要将预览服务器用作真实机器人。

构建 App 后可运行 `node scripts/console-desktop-preview.js`，在独立临时目录中将打包 App 接入同一虚构预览宿主，退出时清理。使用 `HERMES_QQ_BUILD_OUT` 指定构建目录。

验收覆盖 1440、1100、768、390px 的所有页面，主要编辑页面深浅主题，以及切页、状态刷新、保存失败和版本冲突。构建与验收不等于部署；替换当前 App 需要另行授权。
